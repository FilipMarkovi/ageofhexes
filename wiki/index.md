# Age of Hexes Knowledge Bundle

Welcome to the Age of Hexes developer wiki. This bundle is organized using the **Open Knowledge Format (OKF) v0.2**, ensuring it is both human-readable and agent-friendly.

## Project Vision

Age of Hexes is a fast-paced, hexagonal real-time strategy (RTS) game optimized for low-latency web play. It features a territory-control economy and automated bot systems.
